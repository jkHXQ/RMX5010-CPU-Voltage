# RMX5010 / SM8750 CPU 档位电压查询

**原作者：[jkHXQ](https://github.com/jkHXQ) · GPL-2.0-only · 免费分享，请保留原作者署名及许可证。**

这是已在真我 GT7 Pro（RMX5010 / SM8750）实机验证的 **v2 稳定快照**：通过只读内核模块向 CPUCP 发起新的 SCMI 查询，把返回的档位功耗按已核对的固件算法唯一反解为整数 mV，再显示两簇频率、电压及娱乐评分。

**读到的是档位电压配置，不是 PMIC 引脚的瞬时实测电压，也不是最低稳定电压。** 本项目不进行 CPU 超频、降压或压力测试。

## 下载与使用

从 [Releases](https://github.com/jkHXQ/RMX5010-CPU-Voltage/releases) 下载单个 `.sh`，或下载 ZIP 后解压。

1. 在 MT 管理器中找到 `SM8750_CPU体质测试_MT直接执行_v2.sh`。
2. 选择“执行”，按提示给予 root 权限。
3. 结果位于 `/sdcard/Download/CPU-voltage-MT-results/`，每次测试生成独立目录。
4. 分享该目录中的 `分享结果.txt`；分享前自行检查设备型号、系统构建信息是否适合公开。

脚本内置 KO，无需另外下载或手动刷入。**ZIP 不是 Magisk/KernelSU 刷机模块。** 无上传功能，不收集序列号、IMEI 或 Android ID。

## 输出与评分

保留青色边框、“这是原作者的体质”对照及转转／闲鱼玩笑文案。每簇 16 档的娱乐分数为：

```text
score = trunc(Σ((1100 - 电压mV) × 权重) / 16)
最高频点权重 = 95；其余频点权重 = 5
综合分 = trunc((两簇整数分数之和) / 2)
```

综合分是本项目新增规则。原作者旧样本：大核 **3176**，超大核 **1818**，综合 **2497**。后续同机采样为 **3217 / 1856 / 2536**；部分频点相差 4 mV，原因未确认，项目没有写电压。

因此分数不是永久不变的芯片等级，不能用于判断故障、最低稳定电压、超频空间或二手交易价值。不同手机结果不同，也不能单凭这一点证明表正在生效。
